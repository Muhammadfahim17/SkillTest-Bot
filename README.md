# 🚀 SkillTest Bot — умный Telegram‑бот для проверки навыков программирования

---

## 🌟 Обзор проекта

**SkillTest Bot** — это современный и удобный Telegram‑бот, созданный для **самопроверки знаний в программировании** в формате интерактивных тестов.

Бот помогает пользователям:

* 📊 честно оценить свой уровень знаний;
* 📚 увидеть ошибки и правильные ответы;
* 🏆 попасть в недельный рейтинг лучших;
* 🤖 получить советы от ИИ‑ассистента;
* 🚀 сохранить мотивацию и расти дальше.

> 🔥 **SkillTest Bot** — это не просто тесты, а полноценный учебный тренажёр.

---

## 🎯 Цель бота

Главная цель проекта — **помочь студентам и начинающим разработчикам** понять свой текущий уровень и увидеть направление для роста.

Бот используется в сфере:

* 🎓 образования;
* 💻 программирования;
* 🧠 самообучения;
* 🧪 подготовки к собеседованиям.

---

## 🧠 Что умеет SkillTest Bot

### 📝 Тестирование

* выбор языка программирования (на данный момент — 🐍 Python);
* 3 уровня сложности: 🟢 лёгкий, 🟡 средний, 🔴 высокий;
* тест из **10 вопросов**;
* варианты ответов с кнопками;
* возможность остановить тест в любой момент.

### 📊 Результаты

* подсчёт правильных ответов;
* подробный разбор каждого вопроса:

  * ✅ правильный ответ;
  * ❌ ошибка пользователя;
* мотивационное сообщение в конце теста.

### 🏆 Рейтинг

* автоматическое сохранение результатов;
* **топ‑10 пользователей недели**;
* честная конкуренция и азарт.

### 🤖 ИИ‑ассистент

* советы, как лучше проходить тест;
* рекомендации, что изучать дальше;
* источники проектов для портфолио;
* объяснение преимуществ бота.

## 🎨 Интерфейс бота

SkillTest Bot имеет **красивый и интуитивно понятный интерфейс**:

* 📱 удобное главное меню;
* 🎛 кнопки вместо ввода команд;

## 🧩 Архитектура проекта

Проект реализован на **Python** с использованием **aiogram 3**.

### ⚙️ Основные технологии

* 🐍 Python 3.9+
* 🤖 aiogram 3
* 🔄 FSM (Finite State Machine)
* 📁 JSON‑хранилище данных

### 🗂 Структура проекта

```text
project/
├── main.py          # основной файл бота
├── api_token.py     # токен Telegram‑бота
├── scores.json      # рейтинг пользователей
├── README.md        # описание проекта
```

## 🛠 Установка и запуск

### 1️⃣ Клонирование проекта

```bash
git clone <repo-url>
cd SkillTestBot
```

### 2️⃣ Создание виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate   # Linux / macOS
.venv\Scripts\activate     # Windows
```

### 3️⃣ Установка зависимостей

```bash
pip install aiogram
```

### 4️⃣ Добавление токена

Создайте файл `api_token.py`:

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

### 5️⃣ Запуск бота

```bash
python main.py
```

Если всё успешно — вы увидите:

```text
SkillTest Bot запущен!
```

## 📚 Как добавлять вопросы

Вопросы находятся в словаре `QUESTIONS` в `main.py`.

Формат одного вопроса:

```python
{
  'q': 'Текст вопроса',
  'options': ['A', 'B', 'C', 'D'],
  'correct': 1
}
```

📌 Рекомендуется:

* добавлять минимум **10 уникальных вопросов** на уровень;
* использовать одинаковую индексацию ответов;
* в будущем вынести вопросы в отдельный JSON‑файл.
